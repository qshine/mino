# 第 07 章：项目文件工具

状态：**已实现并发布**（`chapter-07`，版本 `0.7.0`）。前置：[工具循环](./03-tools-and-bash.md)、[预算](./05-context-budget.md)，以及第 06 章 `skill_view` 形成的受限只读工具先例。公共约定见[计划索引](./README.md)。

## 1. 本章交付与边界

加入两个结构化工具：`read_file` 读取项目内的一个普通文件，`write_file` 新建或整体覆盖项目内的一个普通文件。用户能观察到：模型读取文件时不需要逐次批准，但读不到项目目录之外的内容；模型写文件时，界面显示目标路径、新建还是覆盖，以及将写入内容的有界摘要，默认拒绝。

本章的教学目的，是给第 09 章提供一个**能被代码真正限定范围**的对照对象。通用 Bash 的任意字符串无法可靠映射成文件操作，路径规则约束不了它；结构化工具的参数则可以在执行前完整校验。

不做：删除、移动、目录创建、按行编辑或补丁格式、二进制文件、通配符和递归操作、受保护路径策略。删除留给第 09 章作为策略示例；受保护路径（配置、历史、凭证）由第 09 章统一定义。Bash 保持第 03 章的逐次批准，不因新增文件工具而放宽。

## 2. 路径与范围

- 项目根沿用启动时捕获的 Bash 工作目录（与第 06 章 Skills 的项目根相同）；`/new` 不改变它。
- 参数只接受相对于项目根的路径。拒绝绝对路径、空路径、NUL、`..` 越界；用 `os.Root` 打开，让越界与符号链接逃逸由标准库在每段路径上拒绝，不用 `strings.HasPrefix` 判断归属。
- 只处理普通文件；目录、设备、FIFO、socket 和符号链接目标一律拒绝。多硬链接文件是否拒绝在开章时讨论。
- 读取上限沿用 64 KiB（`tools.OutputLimit`），超限报错而不是静默截断；必须是有效 UTF-8。写入内容同样以 64 KiB 为上限。

## 3. 读取：受限只读，免确认

`read_file` 的 `Prepare` 在确认路径位于项目根内后，把调用标记为 `ReadOnly`，与 `skill_view` 一样跳过确认；这个标记只能由可信工具代码设置，不从模型参数解码。读取结果作为普通配对工具结果保存和回放，计入上下文预算和每轮 16 次工具调用上限。

需要在教程中说明代价：读取到的内容会发送给配置的模型服务。本章不区分敏感文件；项目中的 `.env` 等文件同样可读，这是第 09 章受保护路径要解决的问题。

## 4. 写入：逐次批准，绑定确切内容

`write_file` 参数为相对路径、完整内容，以及明确的 `mode`：`create`（目标必须不存在）或 `overwrite`（目标必须已存在且为普通文件）。不提供“存在则覆盖、否则新建”的模糊模式。

1. `Prepare` 校验参数，确定目标当前状态，生成确认字段：路径、模式、字节数、内容的有界预览；覆盖时同时显示原文件大小。
2. 默认拒绝；用户批准后，`Execute` 重新校验目标状态与 `mode` 是否仍然一致。目标在批准后出现、消失或变成链接，都放弃执行并返回 `not_executed`，不扩大原批准范围。
3. 写入同目录临时文件，sync 后原子替换，再 sync 目录。父目录必须已存在。
4. 写入前先持久化 `tool_start`；中断恢复按第 03 章规则标记 `not_executed` 或 `unknown`，不重新写入。

## 6. 已确认的决定（2026-10-11）

- 项目目录内的读取免确认（`ReadOnly`），与 `skill_view` 一致。
- 加入 `edit_file`：参数为路径、`old_string`、`new_string`；`old_string` 必须非空且在文件中恰好出现一次，替换后整体写回。确认时显示行号、删除和插入的内容预览。
- 拒绝多硬链接目标（读、写、编辑都拒绝）。
- 写入和编辑的预览最多显示 20 行、2 KiB，并显示字节数和行数；覆盖时显示原文件大小。

实现约束：恢复历史时会对 `tool_start` 重新调用 `Prepare` 并比较参数，所以 `Prepare` 只做与文件系统无关的参数校验。读取当前文件、生成确认预览、记录内容摘要放在只对实时调用执行的 `Inspect` 步骤里；`Execute` 在批准后重新核对摘要，文件在批准后发生变化就不写入。

Mino 的数据目录（`~/.mino`，包含 API 密钥和会话历史）如果位于项目目录内（例如从用户主目录启动），文件工具拒绝执行，避免免确认的读取泄露配置。这是随工具引入的基础保护，第 09 章再统一受保护路径。
