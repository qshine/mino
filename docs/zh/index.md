# 用 Go，从零构建一个 Agent

**一本随着 Mino 的代码逐章生长的图文教程。**

一个模型接口如何变成能在终端里对话的程序？程序又如何获得记忆、调用工具、保存会话，并在明确的授权范围内行动？这本书沿着这些问题，一次增加一种能力。

你可以先运行每一章的成果，再沿着流程图和代码理解它为什么这样工作。这里的图用于解释数据和控制如何流动，终端示例用于展示可以观察到的行为。

## 适合谁读

你已经了解 Go 的变量、函数和基本错误处理，希望理解 Agent 的工作方式。第一次接触模型 API 也可以从第一章开始；HTTP 请求、上下文、工具调用等概念，会在真正需要它们时展开。

Mino 面向 macOS，应用目前只使用 Go 标准库。阅读本书不需要安装网站构建工具；下载运行 Mino 也不需要安装 Go。只有学习或修改源码时才需要 Go，维护书籍网站时才需要 Node.js。

## 每章会给你什么

1. **一个具体问题**：上一章的程序在哪里不够用？
2. **本章目标**：读完之后，程序多了什么可运行的能力？
3. **原理和图解**：通过概念图、流程图或时序图，解释一次操作发生了什么。
4. **实现路径**：找到负责这件事的代码，理解关键取舍。
5. **小实验与验证**：自己观察结果，并用测试确认边界。
6. **本章完成了什么**：分清已经实现的能力和留给下一章的问题。

## 如何配合代码阅读

章节开头会注明适用版本，关键源码链接指向核对过的版本标签。这样即使后面代码继续演进，你仍能找到对应章节讲解的实现。

版本使用 `0.章节.修订号`：第一章是 `0.1.0`，同章修复是 `0.1.1`；第二章从 `0.2.0` 开始。小修复会更新相关说明和图表，不会凭空多出一个新章节。
