# 关于作者

**qqling | AI Builder**

我想从零构建一个属于自己的 Agent，Mino 就是这个想法的起点。

我希望通过这个项目长期研究 Agent，把构建过程中的理解和实践整理成适合入门者的教程。每增加一种能力，就说明它解决什么问题、怎样工作，以及如何验证结果，让刚接触 Agent 的读者也能一步步跟上。

这份教程会随着 Mino 一起生长。目前可以从终端问答和对话历史开始学习，后续研究与实现方向见[章节路线](./plan-todo-chapters.md)。
