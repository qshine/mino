# 用 Go，从零构建一个 Agent

**一本随着 Mino 的代码逐章生长的图文教程。**

一个模型接口如何变成能在终端里对话的程序？程序又如何获得记忆、调用工具、保存会话，并在明确的授权范围内行动？这本书沿着这些问题，一次增加一种能力。

先观察一段简短交互，再追踪用户提供什么、模型收到什么、程序接下来做什么。图解和源码链接用于说明数据与控制如何流动，小实验让能力边界变得可观察。

## 适合谁读

你已经了解 Go 的变量、函数和基本错误处理，希望理解 Agent 的工作方式。第一次接触模型 API 也可以从第一章开始；HTTP 请求、上下文、工具调用等概念，会在真正需要它们时展开。

Mino 面向 macOS，使用 OpenAI 官方 Go SDK 完成 API 通信。本书用 Go 实现 Mino 的交互流程，以及后续的 Agent 循环。阅读本书不需要安装网站构建工具；下载运行 Mino 也不需要安装 Go。只有学习或修改源码时才需要 Go，维护书籍网站时才需要 Node.js。

## 每章会给你什么

每章沿着一次具体交互，只展开理解它所需的代码，再用小实验检验结果，明确已经具备的能力和留下的问题。安装与配置集中在[准备与安装](./getting-started.md)，章节通过链接引用，不重复设置过程。

## 如何配合代码阅读

章节开头会注明适用版本，关键源码链接指向核对过的版本标签或固定的开发版提交。这样即使后面代码继续演进，你仍能找到对应章节讲解的实现。

版本使用 `0.章节.修订号`：第一章是 `0.1.0`，同章修复是 `0.1.1`；第二章从 `0.2.0` 开始。小修复会更新相关说明和图表，不会凭空多出一个新章节。

从[准备与安装](./getting-started.md)开始，或直接阅读[第一章](./chapters/01-terminal-chat.md)。
