# 用 Go，从零构建一个 Agent

**从一次交互理解 Agent 的工作方式，用代码和实验验证原理。**

作者：[qqling | AI Builder](./about-author.md)

Mino 是一个用 Go 从零构建 Agent（智能体）的项目，这本教程记录它逐章增加能力的过程。你会从终端问答开始，看清模型收到什么、程序负责什么，再亲手检验每一步的结果和边界。

**已完成：**[第一章：与模型对话](./chapters/01-terminal-chat.md) · [第二章：JSONL 对话历史](./chapters/02-jsonl-history.md)。工具与多会话由后续章节发布版提供，见[章节规划](./plan-todo-chapters.md)。

## 适合谁读

这本书面向刚接触 Agent、希望动手理解其原理的读者。阅读源码需要了解 Go 的变量、函数和基本错误处理；第一次接触模型 API 也可以从第一章开始。HTTP 请求、上下文、工具调用等概念，会在真正需要它们时展开。

跟练环境是 macOS。下载运行 Mino 无需安装 Go，从源码构建或运行 Mino 时需要安装 Go；具体步骤见[准备与安装](./getting-started.md)。

## 每章会给你什么

1. **观察一次交互。** 从输入问题、看到回答等具体动作开始，明确这一章要解决的问题。
2. **看清模型与程序的分工。** 配合图解和对应版本的源码，追踪输入、上下文与响应如何流动。
3. **用实验验证。** 检查请求内容或运行模拟测试，确认能力来自哪里、在什么情况下会失效。

例如，第一章通过检查请求说明为什么同一个终端里的两次提问没有记忆，第二章再验证保存的历史怎样进入下一次请求。模型碰巧答对，不能替代对程序行为的检查。

## 如何配合代码阅读

章节开头会注明适用版本，关键源码链接指向对应的 `chapter-NN` 发布标签。这样即使后面代码继续演进，你仍能找到对应章节讲解的实现。

发布标签使用 `chapter-NN`，程序版本采用 `0.章节.修订号`。例如，补丁标签 `chapter-04.1` 生成版本 `0.4.1`，并更新对应章节的说明，无需新增一章。

使用过早期 `0.1.0` 构建的读者，请按[更新说明](./getting-started.md#查看版本和更新)操作。
