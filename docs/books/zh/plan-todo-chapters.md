# Mino 章节规划与完成状态

本教程使用 Go 和 OpenAI Responses API，从零实现一个终端 Agent。OpenAI 官方 Go SDK 负责 API 通信，Mino 实现交互流程，以及第三章引入的 Agent 循环。每章追踪一次交互：模型收到什么，程序怎样处理响应，控制或上下文如何进入下一步。[准备与安装](./getting-started.md)集中说明安装和 API 设置。

第 01–05 章均已发布，具备代码、双语说明和验证。第五章于 **2026-09-26** 随 **chapter-05** 发布，程序版本为 **0.5.0**。表格区分「已发布」「未开始」；第 06–08 章仍在规划中。

## 第 05 章的实现边界

第 05 章合并了原来的手动与自动压缩章节。[正文](./chapters/05-context-compaction.md)解释共同的交互流程及模拟请求检查；[准备说明](./getting-started.md#配置上下文窗口)介绍 `context_window`，省略或为零时采用 **128,000 tokens**，不探测模型元数据。

本地估算使用序列化 UTF-8 字节数和封装余量，预留输出空间，在输入预算超过 80% 时触发；它不是精确分词器。每次压缩最多发送一次不带工具的摘要请求，每轮问答最多自动尝试一次。材料过大、摘要失败或无法缩短上下文、压缩后仍超过预算硬上限时都会报错，不进行递归或分批压缩。原始记录继续保留，因此压缩不负责清理磁盘空间。真实模型质量和服务商兼容性仍不在模拟测试的证明范围内。
